# tree-packs

Theme packs for [Tree](https://uncle-jasper.github.io/tree/), Ginkgo and the Tree Obsidian plugin.

A pack is a small file holding a set of themes: their colors, and settings for effects like falling rain or neon light. The apps list the packs here on their Packs screen and install them with one tap. You can also download a pack file and import it.

| Pack | Themes |
|---|---|
| Rain | overcast, rain, downpour, wet street, wet neon |
| Judgment Day | cyberdyne, liquid metal, steel mill, hud |

The format is described in [FORMAT.md](FORMAT.md). Pack files hold only colors, names and effect settings, never code.
